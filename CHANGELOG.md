# Changelog

## 0.3.3 — 2026-10-05

Editable 0–100% opacity with synchronized slider; HSV wheel, brightness, custom
HEX/RGB preview, swatches and recent session colors for primary/gradient colors.
Labeled toolbar groups and sidebar option cards. Selection/undo loads object style
values, with a nearby Apply style action. Pantone library is not bundled.

## 0.3.2 — 2026-10-05

Eraser supports drag-window deletion: left-to-right fully encloses object bounds,
right-to-left crosses bounds (actual stroke for Line). Preview highlights the batch;
release deletes it with one undo step. Click erases one object; Esc cancels the drag.

## 0.3.1 — 2026-10-05

Add a persistent Select objects button at the start of the editor toolbar, accessible
from every tool category. The button highlights while Select is active; V remains the shortcut.

## 0.3.0 — 2026-10-04

All seven editor categories active: expanded shape/path tools, line patterns/weight/endpoints,
solid/gradient/opacity/rotation, editable numeric/alphabetic steps, callouts/notes,
revision clouds, calibration and measurements, 14 basic drawing symbols. Image composition
from history/clipboard/files, canvas expansion, multi-selection/resize/layer order,
versioned editable `.snapmark` projects, local MP4 screen recording through external FFmpeg.
Contextual options and local-only workflow; cloud deferred. 99 validation assertions.

## 0.2.0 — 2026-10-04

Design MVP P1-A: seven tool categories, editable Blur/Pixelate/Solid cover, 29 design
stamp definitions and custom text, style presets/apply-to-selection, text/stamp metric
selection, opt-out original history, command-line image open. Shared preview/export
processing and pixel-level regression coverage for effects and stamps.

## 0.1.0 — 2026-10-04

Initial SnapMark foundation: Windows capture, frozen region overlays, tray and global
hotkeys, vector editor, undo/redo, clipboard, PNG, local history/settings and portable packaging.
